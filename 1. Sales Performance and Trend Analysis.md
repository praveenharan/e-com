## This links appointment facts to the admission dimensions to see downstream impacts.

### Using SQL

```sql
SELECT 
    a.DiagnosisCode,
    COUNT(a.AdmissionID) AS Total_Admissions,
    ROUND(AVG(a.LengthOfStay), 1) AS Avg_Days_In_Hospital,
    MAX(a.LengthOfStay) AS Max_Stay
FROM gold_lh.dbo.dim_admissions a
GROUP BY a.DiagnosisCode
ORDER BY Avg_Days_In_Hospital DESC;

```
