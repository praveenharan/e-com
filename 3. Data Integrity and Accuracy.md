# 3. Data Integrity and Accuracy

### 1. SQL Audit Query
```SQL
SELECT 
    order_id,
    SUM(qty * unit_price) AS calculated_total,
    SUM(line_total_amount) AS reported_total,
    ABS(SUM(qty * unit_price) - SUM(line_total_amount)) AS variance,
    CASE 
        WHEN ABS(SUM(qty * unit_price) - SUM(line_total_amount)) > 0.01 THEN 'FLAG: DISCREPANCY'
        ELSE 'MATCH'
    END AS audit_status
FROM fact_sales
GROUP BY order_id
HAVING variance > 0.01; -- Only show discrepancies exceeding the threshold
```

### 2. PySpark Implementation

```SQL
from pyspark.sql import functions as F

# 1. Aggregate line items to Order level
order_audit_df = spark.table("fact_sales") \
    .groupBy("order_id") \
    .agg(
        F.round(F.sum(F.col("qty") * F.col("unit_price")), 2).alias("expected_total"),
        F.round(F.sum("line_total_amount"), 2).alias("actual_total")
    )

# 2. Calculate variance and apply threshold flags
threshold = 0.01
audit_results = order_audit_df.withColumn(
    "variance", F.abs(F.col("expected_total") - F.col("actual_total"))
).withColumn(
    "is_anomaly", F.when(F.col("variance") > threshold, True).otherwise(False)
)

# 3. Filter for stakeholders to review
discrepancies = audit_results.filter(F.col("is_anomaly") == True)
discrepancies.show()
```
